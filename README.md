## What's This

This thing can help you to make a choose when you dosen't know how to make a choose.

And...You might say: "I can flip a coin to decide.", right?

But if you have to make a recurring decision, such as "*Where should I go for a walk tonight?*", wouldn't flipping a coin be a bit inconvenient?

## How to Use

- First, Open the website of this repo. (*sounds like I said nothing...*🤡)

- Then, Add a new box and papers. Use `Manage` button to move papers into the box

- Finally, Click the yellow button at the bottom of the screen.
